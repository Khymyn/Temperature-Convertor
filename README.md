# Temperature Converter

## Description

This is a simple temperature converter written in C. The program allows the user to convert temperatures between Celsius, Fahrenheit, and Kelvin. The user enters a temperature and chooses the units for conversion. The program then calculates and shows the result.

## Purpose

I created this project to practice the basics of the C programming language. While working on it, I practiced using variables, input and output, mathematical operations, and conditional statements.

## Future Improvements

In the future, I would like to improve input validation and add more features to the program. I also want to improve the interface.
